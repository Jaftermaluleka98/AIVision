# AIVision - AI Vision Application

AI Vision application built with Python, Flask and Machine Learning for real-time image analysis.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Flask](https://img.shields.io/badge/Flask-2.0-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

## 🚀 Features
- Real-time image detection / classification
- Upload image or use live camera feed
- Flask web interface
- Machine learning model integration (TensorFlow / OpenCV)
- REST API ready

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **AI/ML:** OpenCV, TensorFlow / PyTorch, NumPy
- **Frontend:** HTML, CSS, JavaScript
- **Other:** Git, GitHub
